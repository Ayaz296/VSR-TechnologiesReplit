Create a flashy, immersive static website for VSR Technologies, a company that provides security systems, networking solutions, CCTV surveillance, structured cabling, installation, commissioning, maintenance, and basic AI-assisted threat surveillance.

IMPORTANT BRAND POSITIONING:
This is a real-world security and infrastructure company, not a SaaS dashboard startup. The design should feel premium, visually impressive, and futuristic, while still grounded in real engineering and security services.

OVERALL STYLE:

* Light-mode dominant
* Very modern and visually striking
* Flashy 3D scenes and immersive motion
* Premium corporate-tech aesthetic
* Clean typography with cinematic layout composition
* Different background colors across selected sections
* Strong sense of depth, lighting, and movement
* High-end product-launch style presentation

VISUAL DIRECTION:

* Large 3D hero scene
* Floating surveillance hardware elements
* Abstract network structures
* Glassmorphism panels
* Layered parallax motion
* Smooth section reveals
* Rotating or animated 3D objects
* Glow accents used selectively
* Flashy but elegant, not messy

COLOR PALETTE:

* Main base: white / soft off-white / light silver
* Accent sections in:

  * soft blue
  * pale steel grey
  * light cyan
  * subtle red for fire/security alert sections
  * one darker premium section if needed for contrast
    Use color changes by section to create a dynamic scrolling experience.

WEBSITE STRUCTURE:

1. HERO SECTION

* Full-screen, immersive
* Light-mode futuristic environment
* Large 3D centerpiece such as a floating CCTV lens system, security sensor ring, or abstract surveillance device
* Headline: “Advanced Security & Infrastructure Solutions”
* Supporting text covering CCTV, networking, installation, maintenance, and AI-assisted surveillance
* CTA buttons: “Explore Solutions” and “Contact Us”
* Motion-rich background with soft particles, gradients, light beams, and parallax layers

2. SERVICES SECTION

* Premium service cards inspired by real-world business sectors
* Services:

  * CCTV Surveillance
  * Video Analytics
  * Networking Solutions
  * Building Management
  * Smart City Solutions
  * Entrance Control
  * Fire Alarm Systems
  * Parking Management
* Each card should include strong imagery, glass overlays, hover depth, tilt interaction, and polished typography

3. 3D INFRASTRUCTURE SHOWCASE

* A visually impressive section featuring abstract 3D cables, nodes, data pathways, and connected infrastructure
* Emphasize structured cabling, network systems, and integrated security deployment
* Make it immersive and flashy, but still relevant to real infrastructure work

4. AI THREAT SURVEILLANCE SECTION

* Focus on basic AI-assisted surveillance and threat detection
* Do not make it look like a software dashboard company
* Use one cinematic 3D scene with scanning beams, camera focus rings, motion tracking lines, or subtle red signal pulses
* Messaging should stay realistic and grounded

5. INDUSTRIES SECTION

* Showcase support for airports, commercial buildings, and industrial sectors
* Use strong editorial layout with large imagery, layered cards, and subtle 3D transitions

6. WHY CHOOSE US

* Clean but visually refined section
* Emphasize:

  * tailored solutions
  * end-to-end delivery
  * installation and commissioning
  * maintenance and long-term support
  * experience in critical infrastructure
* Can include floating icon blocks or layered panels

7. CONTACT / CTA SECTION

* Premium final section with bold typography and minimal form
* Stylish, immersive, polished
* Optional background using abstract grid/light patterns

DESIGN RULES:

* Light mode should dominate the website
* 3D scenes should be used heavily in hero and key sections
* Avoid overusing fake dashboards or startup UI panels
* Maintain a balance between flashy visuals and corporate trust
* The design should feel expensive and modern
* Section transitions should feel cinematic
* Use full-width layouts and strong spacing
* Keep the content readable and professional

TECH REQUIREMENTS:

* Static website
* React + Tailwind CSS
* Framer Motion for animations
* React Three Fiber / Three.js for major 3D scenes
* Fully responsive
* Production-quality structure
* No backend

OUTPUT:
Generate a high-end, light-themed, immersive static website for a security and infrastructure company, using flashy 3D scenes, elegant motion, and section-based color variation, while keeping the messaging grounded in CCTV, networking, installation, maintenance, and AI-assisted surveillance.
